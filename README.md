## 🚀 Projetos em Destaque

### 🔧 [Sistema de Gestão de Pedidos com Microsserviços](https://github.com/rodrigorcw)
> Backend baseado em microsserviços para gerenciamento de pedidos, estoque e notificações.

- ✅ Arquitetura de microsserviços com Spring Boot 3
- ✅ Comunicação assíncrona com **RabbitMQ**
- ✅ Integração entre serviços via **OpenFeign**
- ✅ Persistência com **PostgreSQL** + containerização com **Docker**
- ✅ Testes com **JUnit** e **Mockito**

`Java 17` `Spring Boot` `RabbitMQ` `OpenFeign` `PostgreSQL` `Docker`

---

### 🔐 [API de Autenticação Segura](https://github.com/rodrigorcw)
> API de autenticação e autorização com controle de acesso por perfis.

- ✅ Autenticação stateless com **JWT** (Bearer Token)
- ✅ Controle de acesso por roles com **Spring Security**
- ✅ Endpoints protegidos e documentados com **Swagger/OpenAPI**

`Spring Boot` `Spring Security` `JWT` `Swagger`

---

### 🚗 [Car Registration API](https://github.com/rodrigorcw)
> API REST completa para cadastro e consulta de veículos.

- ✅ CRUD completo com **Spring Data JPA** e **PostgreSQL**
- ✅ Arquitetura em camadas: Controller → Service → Repository
- ✅ Validações com **Bean Validation (Jakarta Validation)**
- ✅ Mapeamento de DTOs com **MapStruct** e redução de boilerplate com **Lombok**
- ✅ Documentação com **Swagger/OpenAPI** e testes com **JUnit 5**

`Java 17` `Spring Boot` `Spring Data JPA` `PostgreSQL` `Lombok` `MapStruct` `Docker`

---

### 🔔 [Serviço de Notificações Assíncronas](https://github.com/rodrigorcw)
